# Security and Privacy

This is a sanitized technical portfolio, not a live-environment runbook.

I intentionally exclude credentials, API tokens, private keys, public IP addresses, live DNS or DDNS names, internal addressing, device serial numbers, MAC addresses, SSIDs, port assignments, configuration backups, recovery codes, and screenshots that could identify or expose my environment.

I use placeholders and documentation-only values in configuration examples. They are intended to demonstrate a design pattern, not to be copied into production without adapting and validating them for a specific environment.

If you discover content in this repository that may expose sensitive information, please do not disclose it publicly. Contact me directly through my GitHub profile so I can review the report and take appropriate action.
