# Documentation and Change Management

I use Git and GitHub to document meaningful infrastructure decisions, implementation work, troubleshooting outcomes, and recovery procedures.

I keep detailed operational records in a private repository and maintain this public repository as a sanitized portfolio. Public updates are grouped into clear commits so readers can follow the progression of network design, virtualization, wireless deployment, monitoring, and incident-response work without exposing live infrastructure details.

I use commit signing for future portfolio updates to provide a verifiable record that changes were authored from my configured development environment.
